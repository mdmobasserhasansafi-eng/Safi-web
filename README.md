## 🌟 Architecture & Features

- **3D Robot Centerpiece (S.T.D.R.A.)**:
  - Fully procedural Three.js robotic centerpiece built with React Three Fiber (`@react-three/fiber` & `@react-three/drei`).
  - No external model dependencies or broken asset URLs.
  - Multi-tier articulation: cranial helmet, panoramic glowing cyan visor, hydraulic articulated neck, breastplate facets, pulsing cyan power reactor, counter-rotating holographic gyro rings, floating cyber pauldrons, robotic arms, and ambient micro-particle field.
  - Dynamic studio lighting rig with metallic silver key light, electric cyan rim light, and soft violet ambient fill.
- **Scroll-Synchronized Choreography**:
  - GSAP ScrollTrigger timeline smoothly interpolates robot position, rotation, scale, and gyro ring status across each section.
  - Native scrolling remains fully functional and buttery smooth.
  - Responsive mouse/pointer parallax tracking and idle floating animation.
- **Accessibility & Motion Modes**:
  - Automatically respects `prefers-reduced-motion: reduce`.
  - Manual toggle button in the navigation bar to switch between 3D cinematic mode and an optimized holographic diagnostic HUD.
  - WebGL fallback detection for unsupported devices.
- **Design System**:
  - Palette: Near-black void (`#030508`), metallic titanium and silver surfaces (`#94a3b8`, `#e2e8f0`), restrained electric cyan accents (`#00f0ff`), and soft violet gradients (`#8b5cf6`).
  - Controlled glassmorphism with backdrop blurs, clean typography (Inter, Space Grotesk, JetBrains Mono), and generous whitespace.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+ (tested on Node v24)
- npm v9+

### Installation

```bash
# Clone or navigate to the repository
cd SAFI

# Install dependencies
npm install
```

### Local Development

```bash
# Start Vite development server
npm run dev
```

Visit `http://localhost:3000` to preview the live application.

### Production Build

```bash
# Compile TypeScript and bundle production assets with Vite
npm run build

# Preview production build locally
npm run preview
```

The optimized static assets will be output to the `dist/` directory, ready for deployment.

---

## 🌐 Deployment

This application can be deployed instantly to Netlify, Vercel, Cloudflare Pages, or GitHub Pages.

### Deploy to Netlify
1. Connect your repository to Netlify.
2. Set build command: `npm run build`
3. Set publish directory: `dist`
4. Deploy!
